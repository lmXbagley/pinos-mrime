# Зафиксированная семантика симуляции (v0.2, R3/12)

Один тик = 1 мс. Все формулы ниже — эталон; v0.2 их не меняет.
Юнит-тесты (`./build/mp_test`) проверяют эти пункты напрямую.

## Мембрана (1.5)

```
I_n(t)  = Σ_{s: post==n, enabled} effW(s) · pre_spiked(t − delay_s)
u'      = u + leak·(uRest − u) + I + noise·gauss()
```

- Спайк: `refr == 0 && u >= thr_eff`, где `thr_eff = thr + uThrAdapt + homeoAdj`.
- Порог `thr` не задан → порогового спайка нет (параметр обязателен: R1, валидатор красный флаг).
- После спайка: `u = uRest`, `refr = refrMax`, `traceV = trace` (1.10); `traceV--` каждый тик.
- ALIF (1.5): при любом спайке (пороговом и ручном) `uThrAdapt += gammaConst`;
  иначе релаксация `uThrAdapt *= exp(-homeoRate/1000)` (если `homeoOn`).
- Шум: pRNG детерминированный (LCG + Бокс–Мюллер), seed задаваемый.

## Доставка спайков

Спайк pre в тике T доставляется в тик `T + max(delay, 1)`
(планируется на фазе 5 текущего тика, применяется в фазе 1 тика доставки).

## Сенсоры (1.14–1.18)

- Нормировка по умолчанию (не задана): `[0 .. 1]`.
- Кодирование rate (частотное, детерминированное):
  `hz = 1000 · smooth(n)`, `period = max(1, round(1000/hz))`, спайк при `tick % period == 0`.
- EventDiff: спайк при `|raw − raw_prev| > fireThr` (+гистерезис `hyst`).
- EventOnOff: on — пересечение `fireThr` вверх; off — ниже `fireThr − hyst`.

## Пластичность (2.4–2.8)

- Окно пары: `|t_pre − t_post| <= pw` тиков.
- Применение — ровно в тик пост-спайка: `postSpiked && pairInWindow && plast.set`.
- Хебб: `w += lr`; анти-Хебб: `w -= lr`; reward-gated: `w += lr·M`; жёсткая: без изменений.
- `M = Σ` ставок активных модуляторов (1.25): окно активно, пока `tickNow < until`.
- Нет модуляторов → `M = 0` → reward-gated не меняет вес.
- Распад (2.8): тик без пары спайков → `idle++`, при `idle > 0` `w *= (1 − decay)`.
- Клампы: `|w| ∈ [wMin, wMax]`.

## Модуляторы (1.22–1.25)

Спайк модулятора (пороговый ИЛИ ручной «spike once») открывает окно
`until = tickNow + max(1, round(windowSec·1000))` с уровнем `rate` этого модулятора.
Окно ИНДИВИДУАЛЬНОЕ у каждого модулятора (каждый со своим windowSec/rate), не глобальный MOD_TTL.

## Гомеостат (1.26–1.28)

- `avgHz` — EMA (шаг 1 мс) по спайкам scope-нейронов за окно `integSec`.
- `homeoAdj = kThr · (avgHz − target)` — сдвиг порогов scope-нейронов (1.28).
- Множитель пластичности: `plastScale = 1 + kPlast · (avgHz − target)`, применяется как `lr · max(0, plastScale)`.

## Ручное управление

Ручной спайк «spike once» и ручная подача сенсора учитываются движком
в рамках тех же формул (никаких отдельных «ручных» путей) — см. `src/mp/engine.cpp`.
