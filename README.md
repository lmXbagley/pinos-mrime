# MINOSPRIME (pinos-mrime) v0.2 — full C++ implementation

Не задаётся вопросов по умолчанию (R1): любой параметр юнита либо задан явно,
либо юнит помечен красным и схема валидатором помечена как дефектная.

## Состав

- `src/mp/json.*`      собственный JSON reader/writer (без внешних зависимостей)
- `src/mp/model.*`     документ: нейроны (1.1–1.28), связи (2.1–2.11), зоны, кластеры (3.1–3.4),
                       корректное удаление юнитов (R4), счётчики ID (1.1)
- `src/mp/serialize.cpp` Save/Load ВСЕХ полей (R5: refrMax, disabled, счётчики ID)
- `src/mp/undo.cpp`    единая история мыши И кода, глубина 1024 (7.3), история сборок кода (4.6)
- `src/mp/dsl.cpp`     OpenSCAD-модель DSL (4.1–4.6), сборка как операция НАД документом (R2),
                       ошибки с номером строки, экспорт кода из схемы (4.4)
- `src/mp/engine.cpp`  такт симуляции: LIF/адаптивный LIF, рефракт, шум, след,
                       пластичность (жёсткая/Хебб/reward-gated/анти-Хебб), распад,
                       модуляторы (дофамин/наказание/новизна) с индивидуальными окном/радиусом/ставкой,
                       гомеостат (1.26–1.28)
- `src/mp/validator.cpp` красные/жёлтые флаги (8.1–8.2)
- `src/mp/stands.cpp`  стенды: запись/воспроизведение, хеш схемы, регресс-прогон (9.1–9.4)
- `src/mp/api.cpp`     HTTP API (loopback): get_neuron, set_sensor(s), get_schema, stream (10.1–10.5)
- `src/main_headless.cpp` headless CLI: validate / serve (API) / run-stands
- `tests/`             юнит-тесты K1–K12 (headless-часть) и правил R1–R5

- `src/gui/`           **десктоп-CAD**: SDL2 + OpenGL 2.1, 3D-вьюпорт, HUD, инспектор,
                       панель кода, стенды, файлы (разделы 5–10 директив)
## Настольный CAD (главное приложение)

Зависимость: **SDL2** (OpenGL уже есть в системе).

```
sudo apt install libsdl2-dev          # Debian/Ubuntu
sudo dnf install SDL2-devel           # Fedora
brew install sdl2                     # macOS
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/minosprime_gui [проект.mnp.json]
```

Если SDL2 не найден, цель `minosprime_gui` просто не создаётся — ядро, CLI и тесты
строятся как раньше.

Что внутри (по разделам директив):

- **2D-вьюпорт** (вид сверху): СКМ — панорама / колесо зум; камера всегда
  в top-down (yaw 0, pitch ≈90°); пик экранный, хитбокс точно по кругу нейрона;
  ID-билборды, импульсы бегут по связям, яркость нейронов ∝ активности
  (или сумме входных весов — тумблер «Веса»), цвет связи = знак (красный/зелёный),
  толщина ∝ |w|, подсветка соседей выбранного юнита.
- **Режимы мыши** (5.1–5.10): `S` выбор (рамка, перенос группы), `N` — установка
  нейрона через окно параметров ДО установки, `C` — связь в два клика (окно
  параметров, дубль не создаётся — открывается существующая), `X` — вырезание,
  `D` — поврежнение; удержание ЛКМ на нейроне ≥0.4 с — окно потока (5.9);
  ПКМ — контекстные меню (нейрон/связь/кластер/сцена).
- **Режим движения** (HUD «Движ» или `G`): сначала выдели нейроны (рамка/клики в
  «Выбор»), затем `G` — тяни ЛКМ в плоскости, вся группа едет за курсором;
  СКМ в этом режиме тоже двигает группу; `Enter` — выход, `Esc` — отмена.
- **Фуллскрин**: `F11`, кнопка `FS` в HUD или запуск с `--fullscreen`.
- **Редактор кода**: выделение мышью и `Shift+стрелки`; `Ctrl+C` — копировать
  (без выделения — текущая строка), `Ctrl+V` — вставить, `Ctrl+K` — вырезать строку,
  `Ctrl+X` — сохранить проект и собрать; `Backspace` — удаление одного символа,
  при удержании продолжает удалять; текущая строка и выделение подсвечиваются,
  строка с ошибкой — красным.
- **Кластеры** (3.x): создание мышью через DSL-код (`ПКМ → Новый кластер`),
  развёртка через «Код → Собрать», заполнение активностью.
- **Панель кода** (4.1–4.6): OpenSCAD-подобный DSL, «Собрать» — операция НАД
  документом (R2), ошибки подсвечивают строку и кликабельны, конфликты ведут
  камерой к юниту, «Экспорт».
- **Инспектор** (1.x/2.x/3.x): все 28 параметров нейрона, 11 параметров связи,
  параметры кластера; Opt-поля с тумблером set/unset — незаданные красят юнит
  красным (R1).
- **HUD** (6.6, 8.3): счётчики, Пуск/Стоп, скорость, отмена/возврат (глубина 1024),
  статусы API; строка флагов валидатора — клик летит камерой к юниту (8.3).
- **Файлы** (7.1–7.5): открыть/сохранить, автосохранение каждые 30 с,
  недавние проекты, единая undo-история мыши и кода.
- **Стенды** (9.1–9.4): запись действий мыши (5.9), фиксация эталона, прогон,
  регрессия с проверкой хеша схемы.
- **API** (10.x): запуск/останов HTTP-сервера на 127.0.0.1 прямо из GUI.

## Быстрый старт (headless CLI)

В репозитории есть готовый демо-проект `examples/demo.mnp.json`
(зона V1: сенсор → ALIF-скрытый → мотор, Хебб-пластичность + записанный стенд):

```
./build/minosprime validate examples/demo.mnp.json              # флаги R1/8.x (exit 1 при красных)
./build/minosprime stands examples/demo.mnp.json                # регрессия стендов 9.4 (PASS/FAIL)
./build/minosprime serve examples/demo.mnp.json --port 18080    # API на 127.0.0.1 (Ctrl+C — стоп)
```

Пока `serve` работает (1 тик = 1 мс), можно дергать API из браузера или curl:

```
http://127.0.0.1:18080/get_schema
http://127.0.0.1:18080/set_sensor?id=V1.S.1&v=10
http://127.0.0.1:18080/get_neuron?id=V1.H.1
http://127.0.0.1:18080/stream?ids=V1.S.1,V1.H.1,V1.M.1&hz=10
```

## Проекты

Свою схему сохраняйте как JSON в формате `saveProjectJson` (magic «minosprime»),
файл с любым именем `.mnp.json`:

```
./build/minosprime validate my_project.mnp.json
```
